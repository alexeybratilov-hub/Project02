# TESTING

## 1. Текущее состояние

Реализованы ядро (этап 1) и модуль юридических лиц (этап 2). Автоматические тесты: `app/tests/` —
55 тестов (pytest), все проходят. Ручные проверки запуска, сохранения данных между перезапусками
и сценариев юрлиц выполнены в Linux-среде разработки (§5.2, §5.3);
ручная проверка start.bat на целевой Windows не выполнена (нет доступа к Windows) — см. §7.

- интеграционные тесты БД и миграций;
- тесты импорта/экспорта Excel;
- тесты резервного копирования и восстановления;
- ручные сценарии интерфейса.

## 4. Команды запуска

После этапа 1 (утверждённый стек, D-001):

```bat
pip install -r requirements.txt   # установка зависимостей
pytest -q                         # автоматические тесты
runtime\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000  # запуск (или start.bat)
```

Команды действуют с этапа 1 (T1-11 завершён).

### 5.1а Результаты этапа 2 — автоматические тесты (2026-10-23)

Команда: `python -m pytest` (Python 3.12.10, Linux).

Фактический вывод: **55 passed in 5.71s**. Добавлено к этапу 1:
test_legal_entities_service — 24 юнит-теста сервиса (валидация ИНН/КПП/ОГРН, дубликаты 409,
предупреждения, архивирование без удаления связей, импорт add/skip/update/reject, отмена импорта,
экспорт xlsx/csv+BOM, round-trip без потерь, экранирование формульных инъекций);
test_stage2_acceptance — 11 сквозных HTTP-тестов (сценарии 1–5, 12, 14, 19 из §3 + выбор текущего,
архив через UI, виджет главной панели).

История запуска: первый полный прогон этапа 2 — 50 passed / 5 failed. Причины и правки:
1) поиск по кириллице через SQL `LOWER()` не работал в SQLite — фильтры переведены на
Python-нормализацию регистра (`_ci`) в service.py;
2) предупреждение о контрольной сумме ИНН не срабатывало — в тесте использовался ИНН
`7701234560`, который проходит валидацию (правильная контрольная цифра); заменён на `7701234561`;
3) тест архива читал заголовок `location` после авто-редиректа — добавлен `follow_redirects=False`
и проверка 303; assertion про cookie упрощён до `client.cookies.get("saot_current_le") == le_id`;
4) удалена случайная строка `wb = Workbook().load if False else None` в тесте сценария 14.
Алгоритмы контрольных сумм ИНН (10-/12-значного) сверены с эталонными весами — реализация верна.

Повторный полный прогон: **55 passed** — регрессий этапа 1 нет.
