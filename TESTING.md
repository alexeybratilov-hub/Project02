# TESTING

## 1. Текущее состояние

Реализованы ядро (этап 1) и модуль юридических лиц (этап 2). Автоматические тесты: `app/tests/` —
55 тестов (pytest), все проходят. Ручные проверки запуска, сохранения данных между перезапусками
и сценариев юрлиц выполнены в Linux-среде разработки (§5.2, §5.3);
ручная проверка start.bat на целевой Windows не выполнена (нет доступа к Windows) — см. §7.

## 2. Уровни тестирования

- модульные тесты сервисов и валидации;
- интеграционные тесты БД и миграций;
- тесты импорта/экспорта Excel;
- тесты резервного копирования и восстановления;
- ручные сценарии интерфейса.

## 4. Команды запуска

После этапа 1 (утверждённый стек, D-001):

```bat
pip install -r requirements.txt   # установка зависимостей
pytest -q                         # автоматические тесты
runtime\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000  # запуск (или start.bat)
```

Команды действуют с этапа 1 (T1-11 завершён).
