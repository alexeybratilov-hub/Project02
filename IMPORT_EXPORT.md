# IMPORT_EXPORT

## 1. Общий процесс импорта

1. Выбор типа данных.
2. Скачивание шаблона.
3. Заполнение.
4. Загрузка файла.
5. Проверка структуры и обязательных столбцов.
6. Предпросмотр строк.
7. Ошибки, предупреждения, дубликаты.
8. Подтверждение пользователем.
9. Транзакционное сохранение.
10. Отчёт: добавлено, обновлено, пропущено, отклонено.

Режимы: добавить новые; обновить после идентификации; пропустить дубликаты; отменить.

При критической ошибке — откат. Частичное повреждение не допускается.

## 2. Общие правила

- кириллица и пробелы в заголовках;
- допустимые альтернативные названия столбцов;
- необязательные столбцы могут отсутствовать;
- пустые ячейки допустимы для необязательных полей;
- даты: DD.MM.YYYY или дата Excel;
- неизвестные значения справочников не создаются молча;
- существующие данные не перезаписываются только по совпадению ФИО или названия;
- при обновлении показывать изменения.

Реализация: `src/services/excel.ts` (`OPR_HEADERS`, `OPR_ALIASES`, `mapOprHeaders`, `downloadOprTemplate`, `parseOprHazards`, `generateOprPreview`), UI — `src/components/OprImport.tsx`. Шаблон `template_opr.xlsx`.

| 2 | Подразделение | department | да | в пределах юрлица |
| 3 | Должность | position | да | глобальный справочник (D-013) |
| 4 | Номер карты ОПР | card_number | да | уникален в пределах юрлица (идентификация add/update) |
| 5 | Рабочее место (уточнение) | workplace_label | нет | |
| 6 | Дата оценки | assessment_date | нет | YYYY-MM-DD / DD.MM.YYYY |
| 7 | Методика оценки | assessment_method | нет | по умолчанию «Матричный метод 5х5» |
| 8 | Состав комиссии | commission_members | нет | |
| 9 | Идентифицированные опасности | hazards | да | формат в ячейке: `[Категория - ]Название [Т:тяжесть(1-5), В:вероятность(1-5)]`; несколько опасностей — через `;` или перенос строки; без балла — значения по умолчанию Т:2, В:2 (`parseOprHazards`) |
| 10 | Максимальный балл риска | overall_risk_score | нет | при пустом значении — авторасчёт (максимум по опасностям, D-016) |
| 11 | Итоговый уровень риска | overall_risk_level | нет | low/moderate/high/unacceptable; при пустом — авторасчёт |

Алиасы заголовков регистронезависимы («№ карты опр», «карта опр», «балл риска» и т.п.). Ошибки предпросмотра: отсутствующие обязательные колонки/значения (юрлицо, подразделение, должность, номер карты), юрлицо не найдено в базе, нарушена ссылочная целостность. Предупреждения: подразделение/должность отсутствуют — будут созданы автоматически; дубликат номера карты (skip). Некорректные тяжесть/вероятность опасности нормализуются `parseOprHazards` к значениям по умолчанию (Т:2, В:2). Уровни риска при разборе опасностей: low ≤4, moderate 5–9, high 10–15, unacceptable ≥16 (согласовано с `StorageService.computeRiskLevel`). Экспорт карт — `exportOprToXLSX` / `exportOprToCSV`; экспорт плана мероприятий — `exportOprPlanToXLSX` (лист «План мероприятий ОПР»).

## 6. Экспорт

- весь реестр или отфильтрованная часть;
- те же столбцы;
- UTF-8 с BOM для Excel;
- даты DD.MM.YYYY;
- защита от формульных инъекций: ячейки, начинающиеся с `=`, `+`, `-`, `@`, экранируются.

## 7. Ошибки и предупреждения

Ошибки: отсутствует обязательный столбец; неверный тип; неверная дата; отсутствует обязательное значение; нарушена ссылочная целостность.

Предупреждения: возможный дубликат; неизвестное значение справочника; пустое необязательное поле; подозрительный формат СНИЛС.

## 8. Отчёт

Содержит: тип импорта, файл, дату, пользователя/процесс, количество строк, добавлено, обновлено, пропущено, отклонено, список ошибок и предупреждений.
