## 10. Изменения, требующие внимания

- Состояния модулей сохраняются в таблице `module_registry`; при добавлении модулей не забывать, что отключённый в БД модуль не монтируется после перезапуска.
- Аудит значимых операций ядра — через `add_audit` (в транзакции вызывающего) или `write_audit` (автономная транзакция для служебных операций вне HTTP).
- SQLite: WAL + foreign_keys включаются event-listener'ом на каждом подключении; бэкап только через sqlite3 backup API (не cp).
- Migrations forward-only (D-006); новый код схемы — только новой Alembic-миграцией.
- Не вводить unique-ограничение на идентификацию контингента (D-004).

## 13. Инструкции по запуску проекта в текущем состоянии

1. Прочитать `AGENT_GUIDE.md`, `PROJECT_CONTEXT.md`, этот файл, `TASKS.md` (этап 1 — done), `prompts/STAGE_2_LEGAL_ENTITIES.md`.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Тесты: `python -m pytest` (ожидается 20 passed).
4. Запуск приложения (Linux/среда разработки): `python -m uvicorn app.main:app --host 127.0.0.1 --port 8000` (переменные SAOT_* — по желанию, пути создадутся автоматически). На Windows — `start.bat` (проверить при наличии Windows, закрыть T1-10).
5. Миграции применяются автоматически при запуске (SAOT_AUTO_MIGRATE=on); серверный режим: `python -m app.migrate`.
