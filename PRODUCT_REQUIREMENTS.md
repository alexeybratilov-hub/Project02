# PRODUCT_REQUIREMENTS

## 1. Область первой версии

Первая версия включает ядро и три раздела:

1. Главная страница и карточки юридических лиц.
2. Реестр контингента работников.
3. Поимённый список работников.

Модули СОУТ, ОПР, медосмотров, СИЗ, обучения, инструктажей, документооборота, проверок и происшествий **не входят** в первую версию.

## 2. Функциональные требования

### FR-01. Несколько юридических лиц

Система должна хранить несколько юридических лиц в одной базе и разделять связанные данные по юридическому лицу.

### FR-02. Карточка юридического лица

Создание, просмотр, редактирование и архивирование. Поля: полное наименование, сокращённое наименование, ИНН, КПП, ОГРН, юридический адрес, фактический адрес, дополнительные сведения.

Обязательные для создания: полное наименование. Остальные — необязательные.

Проверки: форматы ИНН/КПП/ОГРН, предупреждение о дубликатах. Архивирование вместо каскадного удаления при наличии связей.

### FR-03. Справочник подразделений

Подразделения принадлежат юридическому лицу, поддерживают иерархию (родительское подразделение) и архивирование.

### FR-04. Справочник должностей

Единый справочник должностей. Область действия уточняется решением D-013.

### FR-05. Реестр контингента

Поля первой версии:

| № | Поле |
|---|---|
| 1 | Структурное подразделение |
| 2 | Должность |
| 3 | График работы |
| 4 | Сменность |
| 5 | Номер карты оценки профессиональных рисков |
| 6 | Номер карты СОУТ |
| 7 | Подкласс условий труда |
| 8 | Номера пунктов по приказу № 29н |
| 9 | Номера пунктов по приказу № 342н |
| 10 | Программа инструктажа на рабочем месте |
| 11 | Программа стажировки на рабочем месте |
| 12 | Группа по электробезопасности |

Пункты 29н/342н хранятся структурированно, с возможностью нескольких значений.

### FR-06. Операции с контингентом

Ручное создание и редактирование, импорт/экспорт Excel, поиск, сортировка, фильтрация, проверка обязательных полей и ссылочной целостности, отображение связанных работников, расширение полей.

### FR-07. Поимённый список работников

Поля: ФИО (фамилия, имя, отчество), структурное подразделение, должность, дата приёма, дата рождения, СНИЛС. Отображаемый номер п/п не является идентификатором.

### FR-08. Операции с работниками

Создание, редактирование, импорт/экспорт, поиск по ФИО, фильтрация по подразделению и должности, сортировка, проверка дат, предупреждение о дубликатах, архивирование, связь с юридическим лицом, подразделением, должностью и записью контингента.

### FR-09. Связь работника с контингентом

Работник связывается с подходящей записью контингента. Если связь неоднозначна, система требует выбора пользователя или показывает ошибку. Автоматическая привязка к случайной записи запрещена.

### FR-10. Импорт Excel

Универсальный процесс: выбор типа данных → шаблон → загрузка → проверка структуры → предпросмотр → ошибки/предупреждения/дубликаты → подтверждение → сохранение → отчёт.

Режимы: добавить новые, обновить после идентификации, пропустить дубликаты, отменить.

### FR-11. Экспорт Excel

Экспорт всего реестра или отфильтрованной части. Сохранение данных без потерь. Защита от формульных инъекций.

### FR-12. Поиск, фильтры, сортировка, пагинация

Серверная обработка для больших списков. Не загружать тысячи строк без пагинации.

### FR-13. Журнал изменений

Фиксировать: что, когда, какой объект, значения до/после, пользователь или процесс, связанные действия. Исторические записи не перезаписывать.

### FR-14. Резервное копирование и восстановление

Ручное и автоматическое копирование, выбор места, проверка успешности, дата последней копии, восстановление с предупреждением и предварительной копией, проверка целостности после восстановления.

### FR-15. Реестр модулей

Регистрация, включение и отключение модулей. Отключение необязательного модуля не нарушает ядро.

### FR-16. Главная страница

Наименование, навигация, выбор текущего юридического лица, краткая информация, количество юридических лиц, записей контингента и работников, основные действия, пустые состояния без фиктивных данных.

### FR-17. Расширяемость

Новые типизированные поля, справочники, связи, миграции, обновление шаблонов импорта/экспорта, обратная совместимость.

### FR-18. Архивирование

Связанные данные не удаляются каскадно. Удаление юридического лица с связями заменяется архивированием или отдельной процедурой с проверкой связей.

## 4. Вне области первой версии

- полноценные модули СОУТ и ОПР;
- медосмотры и психиатрическое освидетельствование;
- СИЗ;
- обучение, инструктажи, стажировки и допуски;
- документооборот и ознакомление;
- проверки, нарушения, несчастные случаи;
- календарь сроков и уведомления;
- отчётность;
- интеграции;
- интеллектуальный поиск по нормативным документам.

## 5. Критерии приёмки первой версии

- приложение реально запускается в целевой среде;
- юридические лица, контингент и работники сохраняются в постоянной базе;
- данные нескольких юридических лиц корректно разделяются;
- все первоначальные поля доступны;
- ручное создание и редактирование работают;
- импорт Excel имеет предварительную проверку;
- экспорт сохраняет данные без потерь;
- обнаруживаются ошибки и возможные дубликаты;
- связи целостны;
- история не теряется случайно;
- резервное копирование и восстановление работают;
- основные сценарии протестированы;
- документация соответствует реализации;
- следующий агент может продолжить работу;
- фиктивные кнопки отсутствуют.
