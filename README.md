# Система автоматизации охраны труда (САОТ)

Модульное веб-приложение для автоматизации работы специалиста по охране труда в Российской Федерации. Проект разрабатывается итеративно разными ИИ-агентами; документация является частью проекта и обновляется по фактическому состоянию.

## Текущее состояние

**Стадия: 0 — проектирование. Код приложения не реализован.**

В репозитории присутствует только комплект проектной документации. Пользовательские сценарии пока не работают. Не используйте репозиторий как готовое приложение.

## Назначение

- ведение нескольких юридических лиц в одной базе;
- единая система связанных справочников и реестров;
- реестр контингента работников;
- поимённый список работников;
- импорт и экспорт Excel с предварительной проверкой;
- резервное копирование и восстановление;
- подключение функциональных модулей без переписывания ядра.

## Целевая среда

- Windows 10/11, запуск из папки проекта;
- браузер Chrome/Edge актуальной версии;
- локальное хранение данных без обязательного облака;
- возможность последующего развёртывания на локальном сервере.

Конкретный стек, СУБД и способ упаковки **не утверждены**. См. `DECISIONS.md` (D-001…D-003) и `TASKS.md` (этап 0).

## Планируемая структура папки проекта

```text
/app            — код приложения
/data           — рабочая база данных
/attachments    — связанные файлы
/backups        — резервные копии
/logs           — журналы
/docs           — документация
```

Структура уточняется после утверждения стека.
