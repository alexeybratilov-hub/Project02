# Система автоматизации охраны труда (САОТ)

Модульное веб-приложение для автоматизации работы специалиста по охране труда в Российской Федерации. Проект переписан на React (TypeScript + Vite) с сохранением бизнес-логики, валидаций, моделей данных и визуального стиля.

## Текущее состояние

**Реализованные возможности:**
- **Главная панель (Dashboard):** фактические показатели юридических лиц и модулей, пустые состояния без фиктивных данных, реестр подключённых модулей.
- **Модуль «Юридические лица»:**
  - Полный реестр юридических лиц с поиском по наименованию и ИНН, пагинацией.
  - Детальные карточки с отображением связанных данных (подразделения, контингент, работники).
  - Создание и редактирование с валидацией форматов ИНН (10/12 цифр), КПП (9 цифр), ОГРН (13/15 цифр), расчётом контрольных сумм и проверкой дубликатов (ИНН+КПП, ОГРН — конфликт, наименование — предупреждение).
  - Выбор текущего юридического лица с отображением в шапке приложения.
  - Архивирование вместо удаления с сохранением связей (D-009) и возможность возврата из архива.
- **Импорт Excel (.xlsx / .csv):**
  - Скачивание канонического шаблона `template_legal_entities.xlsx`.
  - Загрузка и разбор структуры (маппинг заголовков и синонимов).
  - Построчный предпросмотр с проверкой форматов, контрольных сумм, поиском дубликатов внутри файла и базы.
  - Режимы «Пропускать дубликаты» и «Обновлять после идентификации» с отображением разницы полей.
  - Транзакционное подтверждение или отмена без изменения данных.
- **Экспорт данных:**
  - Экспорт в `.xlsx` и `.csv` с UTF-8 BOM для корректного отображения кириллицы в Excel.
  - Защита от формульных инъекций (`=`, `+`, `-`, `@`).
- **Журнал аудита (FR-13):**
  - Фиксация всех действий (create, update, archive, restore, import_create, import_update, restore).
  - Снимки состояния «ДО» и «ПОСЛЕ» в JSON.
- **Резервное копирование и восстановление (FR-14):**
  - Экспорт полной копии данных в JSON с манифестом.
  - Восстановление из файла или журнала снимков с автоматическим созданием страховочной копии текущего состояния.
- **Реестр модулей (FR-15):**
  - Управление состоянием модулей без нарушения работы ядра.

## Технологический стек

- **Фреймворк:** React 19, TypeScript
- **Сборщик:** Vite 6
- **Работа с таблицами Excel:** SheetJS (xlsx)
- **Хранение данных:** локальное постоянное хранилище (LocalStorage) с сохранением состояния между сессиями браузера

## Запуск приложения

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (порт 3000)
npm run dev

# Проверка типов
npm run lint

# Сборка для продакшена
npm run build
```
