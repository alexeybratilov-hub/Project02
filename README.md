# Система автоматизации охраны труда (САОТ)

Модульное веб-приложение для автоматизации работы специалиста по охране труда в Российской Федерации. Проект разработан на React (TypeScript + Vite) с полным сохранением бизнес-логики, валидаций, моделей данных и визуального стиля.

---

## Текущее состояние (Этапы 1–5 завершены)

**Реализованные возможности:**
- **Главная панель (Dashboard):** фактические показатели юридических лиц, контингента, работников и модулей, пустые состояния без фиктивных данных, выбор текущей организации в шапке.
- **Модуль «Юридические лица» (Этап 2):**
  - Полный реестр юридических лиц с поиском по наименованию и ИНН, пагинацией.
  - Детальные карточки с отображением связанных данных (подразделения, контингент, работники).
  - Создание и редактирование с валидацией форматов ИНН (10/12 цифр), КПП (9 цифр), ОГРН (13/15 цифр), расчётом официальных контрольных сумм и проверкой дубликатов (ИНН+КПП, ОГРН — конфликт 409, наименование — предупреждение).
  - Выбор текущего юридического лица с сохранением сессии.
  - Архивирование вместо удаления с сохранением связей (правило D-009) и возврат из архива.
  - Импорт юридических лиц из Excel по шаблону `template_legal_entities.xlsx` с предпросмотром и режимами «добавить / обновить».
- **Модуль «Контингент» (Этап 3):**
  - Справочники подразделений (иерархия с привязкой к юрлицу, защита от циклов) и должностей (глобальный реестр по D-013).
  - Классификаторы условий труда (графики работы, сменность, подклассы СОУТ 1–4, группы электробезопасности I–V).
  - Реестр контингента со всеми 12 полями (FR-05), уточнением рабочего места, номерами карт СОУТ и ОПР.
  - Структурированное хранение пунктов приказов Минздрава № 29н (медосмотры) и № 342н (психоосвидетельствование).
  - Импорт контингента из Excel (шаблон 14 колонок) с идентификацией по ключу D-004 `(юрлицо, подразделение, должность, рабочее место)`.
- **Модуль «Работники» и история перемещений (Этап 4):**
  - Поимённый список работников с фильтрацией по организации, подразделению, должности, текстовым поиском по ФИО и СНИЛС.
  - Детальная карточка работника и форма создания/редактирования.
  - Валидация СНИЛС по официальному алгоритму ПФР РФ (D-007, формат `XXX-XXX-XXX YY`).
  - Проверка дат: запрет дат в будущем для даты приёма и даты рождения (FR-08).
  - Детектор дубликатов работников: предупреждения при совпадении СНИЛС или ФИО+даты рождения без блокирующего конфликта и **со строгим запретом автоматического объединения** (IMPORT_EXPORT §5).
  - Явное связывание работника с позицией контингента (FR-09) с проверкой принадлежности к той же организации.
  - Учёт кадровых перемещений (D-005, `employment_history`): автоматическое закрытие предыдущего периода и открытие нового с фиксацией причины перевода и комментария; неизменяемость истории.
  - Импорт работников из Excel (шаблон 10 колонок `template_employees.xlsx`, идентификация строго по СНИЛС + Юрлицо).
- **Экспорт данных и защита от атак:**
  - Экспорт в `.xlsx` и `.csv` с кодировкой UTF-8 BOM для корректного открытия в русском Microsoft Excel.
  - Защита от формульных инъекций (CSV Formula Injection) через экранирование символов `=`, `+`, `-`, `@`.
- **Резервное копирование и целостность данных (Этап 5):**
  - Экспорт полной копии данных в JSON с манифестом и счётчиками всех таблиц.
  - Автоматические копии: перед каждым восстановлением (`pre-restore`), перед пакетным импортом (`auto-import-*`) и суточная автокопия (`auto-daily`).
  - Восстановление из локального файла или журнала сохранённых снимков.
  - Функция проверки ссылочной целостности (`verifyDataIntegrity`, Сценарий 18): выявление разорванных ссылок, перекрёстных юрлиц, циклов в отделах, хронологических нарушений в истории перемещений.
- **Журнал аудита (FR-13):**
  - Сквозное логирование всех действий (create, update, archive, restore, transfer, import) со снимками «ДО» и «ПОСЛЕ» в JSON.
- **Модуль «СОУТ» (Этап 6, 426-ФЗ):**
  - Карты СОУТ с факторами, авторасчётом итогового класса условий труда, гарантий и сроков действия (ст. 8); декларация соответствия (ст. 11).
  - Ознакомление работников под роспись (ст. 5), импорт/экспорт из Excel (`template_sout.xlsx`).
- **Модуль «ОПР» (Этап 7, Приказ Минтруда 776н):**
  - Каталог типовых опасностей (`DEFAULT_OPR_HAZARDS`), карты профессиональных рисков рабочего места.
  - Матрица оценки рисков 5×5 (тяжесть × вероятность): low / moderate / high / unacceptable, авторасчёт итогового уровня.
  - План мероприятий по снижению рисков (сроки, ответственные, статусы), импорт/экспорт Excel (`template_opr.xlsx`, `opr_plan_measures.xlsx`).
  - Интеграция в переключатель модулей, резервное копирование и проверку целостности (`isModuleEnabled('opr')`, `verifyDataIntegrity`).

## Технологический стек

- **Фреймворк:** React 19, TypeScript
- **Сборщик:** Vite 6
- **Работа с таблицами Excel:** SheetJS (xlsx)
- **Хранение данных:** локальное постоянное хранилище (LocalStorage) с возможностью экспорта/импорта полных снимков базы
- **Тестовый раннер:** TSX / Node.js 22 (21 автоматический набор тестов)

## Команды запуска и разработки

```bash

npm install

# Запуск dev-сервера (порт 3000)
npm run dev

npm run lint

# Запуск автоматических тестов (16/16 тестов)
npm test

# Сборка для постоянной эксплуатации
npm run build
npm run preview
```
