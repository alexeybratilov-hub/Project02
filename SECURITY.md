# SECURITY

## 1. Модель угроз (первая версия)

- локальный компьютер с доступом к ПК;
- кража или потеря носителя;
- утечка через экспорт Excel и резервные копии;
- вредоносные файлы Excel;
- SQL-инъекции;
- path traversal при вложениях;
- секреты в репозитории;
- отсутствие авторизации.

## 2. Персональные данные

Обрабатываются:

- ФИО;
- дата рождения;
- СНИЛС;
- дата приёма;
- должность и подразделение.

Требования:

- не передавать во внешние облака по умолчанию;
- ограничивать доступ к СНИЛС в интерфейсе (в перспективе);
- не включать реальные ПДн в репозиторий и тестовые данные;
- защищать резервные копии.

## 3. Планируемые меры

- параметризованные запросы;
- валидация входных данных;
- проверка загружаемых файлов;
- ограничение размера и типов файлов;
- безопасное хранение секретов вне репозитория;
- журналирование значимых действий;
- заготовка авторизации и разграничения доступа;
- резервное копирование с проверкой.

## 4. Импорт Excel

- проверка структуры;
- предпросмотр;
- защита от формульных инъекций при экспорте;
- запрет исполнения макросов;
- транзакционность.

## 5. Резервные копии

- содержат ПДн;
- хранить в защищённом месте;
- не коммитить;
- проверять целостность;
- перед восстановлением создавать копию текущего состояния.

## 6. Известные пробелы

- авторизация не реализована;
- шифрование БД не реализовано;
- аудит безопасности не проводился;
- соответствие 152-ФЗ не подтверждено;
- политика паролей отсутствует.

## 7. Правило

Не утверждать, что приложение соответствует требованиям законодательства о персональных данных, без отдельной проверки реализации, настроек и порядка эксплуатации.
